# Sony-LinkBudsOpen-Mouse 🎧🖱️

**专为手部活动不便及残障人士深度打造的 Sony LinkBuds Open (WF-L910) 全免手头控鼠标驱动系统（Windows + Android 双平台）。**

利用耳机内置的高精度姿态传感器（IMU / 陀螺仪），将您的头部转动转化为丝滑、自然的鼠标/触屏光标移动；并深度融合索尼独家**耳周广域点击（Wide Area Tap）**与**左右歪头手势（Head Tilt Gesture）**、**悬停点击（Dwell Click）**，提供完全无需双手的真正无障碍交互体验。

---

## 🌟 核心特性与无障碍设计

### 1. 三大免手点击体系（左侧左键，右侧右键/返回）
* **🎧 耳机耳周广域点击（Wide Area Tap）**：
  * 利用索尼 LinkBuds 特有的声学与骨传导感应技术，轻扣或双击**左侧脸颊/耳周**即可触发【鼠标左键单击 / 触屏点击】；轻扣或双击**右侧脸颊/耳周**即可触发【鼠标右键单击 / 安卓全局返回 Back】。
  * 驱动底层采用系统级热键截获，**自动屏蔽默认的播放暂停、切歌与音量弹窗**，将其静默转化为硬件级原生按键。
* **🙆 左右歪头手势点击（Head Tilt Gesture）**：
  * **100% 免手纯头部姿态操作**，专为完全无法抬手的高位截瘫、渐冻症等肢体障碍人士研发。
  * 面向屏幕向左微偏头部（默认倾斜 $\ge 10^\circ$）触发【左键/点击】；向右微偏头部触发【右键/返回】。
  * **动作防晃定格锁（Tilt Freeze Lock）**：识别到歪头侧倾时，光标瞬间定格在目标落点 280ms，彻底杜绝动作晃动带跑光标的痛点！
* **⏱️ 悬停停留点击（Dwell Click）**：
  * 将光标移动到目标图标或按钮上保持静止，达到设定时间（默认 0.9 秒）后自动执行左键单击，配备 Tobii 风格环形倒计时进度圈。

### 2. 彻底弃用易跑偏的点头手势与中心校准
* **告别点头跑偏**：垂直点头动作（Pitch 轴）与鼠标垂直移动轴直接重叠，极易导致光标晃动下滑。本项目全面采用独立的**横向侧倾（Roll 轴）**与**耳周敲击**，光标稳如泰山。
* **告别中心校准**：基于 Accela 相对角速度动力学驱动，随时随意转动视线，无漂移感，无需频繁按键重新校准中心。

## 📱 Android 触屏版：触屏拖动与滑动解决方案

触屏手机与电脑最大的不同在于：**手机没有滚轮，浏览内容 100% 依赖手指按住屏幕上下拖拽划动**。为此，Android 版针对残障人士日常刷朋友圈、看新闻、刷短视频提供了三种创新交互方案：

### 方案 1：智能粘滞拖拽（Sticky Drag —— 按住与释放锁定）
* **操作逻辑**：
  1. 敲击左侧耳周（或左歪头）：触发【按下锁定（Touch Down）】。
  2. 光标形态瞬间转变为【橙色抓手脉冲 ✊】，提示当前已牢牢抓住屏幕。
  3. 转动头部，屏幕内容随头部转动同步平滑拖动。
  4. 再次敲击左侧耳周：触发【释放松开（Touch Up）】。
* **防误触保护**：若光标停留在原地超过 2.5 秒未动，系统自动安全释放，防止忘记松开。

### 方案 2：智能轻挑翻页（Flick to Scroll —— 刷长文/短视频神器）
* **无需按住拖拉**：
  * 头部向上轻挑一下（快挑快回）：手机自动向下滑动半屏/一屏（模拟手指上划）。
  * 头部向下微叩一下（快叩快回）：手机自动向上翻页。
  * 看小说、刷资讯、逛网页极度轻松，颈部几乎感觉不到疲劳！

### 方案 3：右耳敲击 = 全局返回键（Back）
* 在 Android 终端上，没有 Windows 的“右键菜单”，但手部障碍人士最费力的操作是点屏幕左上角的小返回箭头。
* 本驱动将**右侧耳周敲击 / 右歪头**直接绑定为系统原生的 **【返回键（Back）】**，随时随地一键返回上一页！

## 🚀 快速上手与下载

### 📥 预编译安装包直接下载 (推荐)
直接前往 **[GitHub Releases 最新发布页](https://github.com/lmikey9550/Sony-LinkBudsOpen-Mouse/releases/latest)** 获取已打包就绪的文件：
* **Windows 单文件绿色免安装版**：`SonyLinkBudsHeadMouse.exe`（无需安装 Python，直接双击运行）
* **Android 手机/平板安装包**：`SonyLinkBudsHeadMouse.apk`

---

### 💻 Windows 电脑版
1. 从 Releases 下载 `SonyLinkBudsHeadMouse.exe`（或源码克隆使用 `python app.py`）。
2. 戴上 Sony LinkBuds Open，电脑连接蓝牙音频后直接双击运行即可。
3. （可选）运行 `python create_shortcut.py` 可在桌面创建带管理员权限的快捷方式。

### 📱 Android 手机/平板版
1. 从 Releases 下载 `SonyLinkBudsHeadMouse.apk` 安装到手机（或 `adb install SonyLinkBudsHeadMouse.apk`）。
2. 打开应用：
   - 授予“显示在其他应用上层（悬浮窗权限）”；
   - 在系统“无障碍”设置中开启 **“Sony LinkBuds 免手头控鼠标服务”**。
3. 戴上耳机连接手机蓝牙，即刻畅享免手操作！进入 App 可在“耳机外设传感器源监测”卡片实时查看当前识别到的耳机传感器与三轴姿态角度。

> [!NOTE]
> **真实外设保护机制（严防手机内置陀螺仪冒充）**：
> Android 版已彻底剔除任何手机内部陀螺仪降级逻辑，100% 仅连接 Sony LinkBuds 耳机硬件传感器。若耳机未连接或蓝牙断开，光标会自动进入锁定静止状态并显示“等待 LinkBuds 耳机连接”，彻底杜绝手持或晃动手机导致光标乱跑的问题。
