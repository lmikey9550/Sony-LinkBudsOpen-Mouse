# Sony-LinkBudsOpen-Mouse 🎧🖱️

**专为 Sony LinkBuds Open (WF-L910) 打造的 Windows 免手操作头控鼠标驱动程序。**

利用耳机内置的高精度姿态传感器（IMU / 陀螺仪），将您的头部转动转化为平滑、自然的电脑鼠标光标移动，并支持**悬停点击（Dwell Click）**与**点头点击（Nod Gesture）**，实现真正免动双手的电脑操控体验。

---

## 🌟 核心特性

1. **0 网络端口 / 纯内核匿名管道直通（Zero-Network Anonymous Pipe）**：
   * 彻底弃用 UDP 网络套接字与监听端口，不占用任何本地网络端口（0 Socket、0 Port Listen）。
   * 基于 Windows 内核匿名管道（Anonymous Pipe）实现底层进程间内存直传，零防火墙拦截，无任何网络弹窗。
2. **A2DP 静音保活机制（防 2.5 秒休眠）**：
   * 攻克索尼固件在“无音频播放 2.5 秒后自动关闭传感器”的休眠机制，后台无声维持微弱音频流保活，保证传感器持久在线。
3. **可视化滑块调节面板（Settings Dialog）**：
   * **悬停单击停留时间滑块**：支持 0.3 秒 ~ 2.5 秒精细调节（推荐 0.7~1.0 秒）。
   * **点头识别灵敏度滑块**：支持 1 ~ 10 级灵敏度调节（等级越高动作要求越小，越容易触发）。
   * **内置实时点击测试区**：拖动滑块后可在设置面板中即时测试点击响应，调到最舒服的手感。
4. **点头光标防跑偏锁定（Nod Anti-Drift Lock & Snapback）**：
   * **瞬时动作抑制**：识别到点头急剧下潜时，光标瞬间定格在目标落点，不再随点头动作而向下位移跑偏。
   * **精确坐标回溯**：点头判定完成后，将光标强制拉回动作发生前的绝对像素锚点执行点击，实现“指哪点哪，微毫不差”。
   * **回弹冷却保护**：点击触发后提供 220ms 动作恢复冻结期，完全抵消头部回正时的晃动。
5. **系统原生级鼠标速度联动**：
   * 自动同步 Windows 控制面板的鼠标指针速度（`control main.cpl`），与手部实体鼠标的手感完全统一。
6. **Accela 自适应防抖滤波算法**：
   * 移植自 OpenTrack 的 Accela 动力学曲线与死区滤波：头部微弱生理震颤完全静止，快速转头迅速跟手，大幅减少颈部疲劳。
7. **纯系统托盘交互与快捷键**：
   * **F12**：瞬时居中校准（重置当前头部自然朝向为屏幕中心）。
   * **F9**：一键暂停 / 恢复头控跟踪（方便交由手部鼠标接管）。
   * 动态三色托盘图标：🟢 正常跟踪中 | 🟡 已暂停 | ⚪ 等待耳机连接。
   * 右键托盘菜单包含：水平/垂直轴向反转、免手点击开关、点头防跑偏开关、开机自启、重新检测与硬件修复等。
8. **配置即时持久化**：
   * 所有设置即时写入 `config.json`，重启电脑或驱动后偏好设置自动无缝恢复。

## 🚀 快速开始

### 1. 准备环境
本项目基于 Python 3.10+ 与 Windows 原生 API 运行。

```bash
# 克隆仓库
git clone https://github.com/lmikey9550/Sony-LinkBudsOpen-Mouse.git
cd Sony-LinkBudsOpen-Mouse

# 安装依赖
pip install -r requirements.txt
```

### 2. 创建桌面快捷方式 (推荐)
运行自带的快捷方式生成脚本，将在桌面创建已自动赋予管理员权限（RunAsAdmin）的快捷方式：
```bash
python create_shortcut.py
```

### 3. 连接耳机与启动
1. 佩戴好 **Sony LinkBuds Open** 耳机，确认电脑蓝牙已连接到耳机音频。
2. 双击桌面上的 **`Sony LinkBuds 头控鼠标`** 图标。
3. 托盘图标变绿即表示已成功直连，戴上耳机即可通过头部转动控制光标！

## ⚙️ 快捷键与常用操作

| 快捷键 / 操作 | 功能说明 |
| :--- | :--- |
| **`F12`** | **居中校准**：将当前头部自然朝向设为屏幕中心点 |
| **`F9`** | **暂停 / 恢复**：暂时停止头控，交由手部鼠标操作 |
| **停留约 0.9 秒** | **悬停点击 (Dwell Click)**：在目标位置停稳后自动触发左键单击 |
| **轻微点头** | **点头点击 (Nod Click)**：快速低头微仰触发左键单击 |
| **托盘右键菜单** | 打开调节滑块面板、开关点击手势、切换水平/垂直反转、开机自启动等 |

## 🛠️ 故障排查

* **首次使用光标不动？**
  * Windows 在蓝牙连接新传感器时可能将节点挂起为 Code 10。右键点击托盘中的耳机图标，选择 **「🔄 重新检测/修复耳机连接」** 即可一键恢复。
* **耳机取下后重新戴上？**
  * 驱动内置智能看门狗，耳机重新连上电脑蓝牙后会在几秒内自动唤醒并恢复跟踪。
