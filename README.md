# Sony-LinkBudsOpen-Mouse 🎧🖱️

**专为手部活动不便及残障人士深度打造的 Sony LinkBuds Open (WF-L910) 全免手头控鼠标驱动系统。**

利用耳机内置的高精度姿态传感器（IMU / 陀螺仪），将您的头部转动转化为丝滑、自然的电脑鼠标光标移动；并深度融合索尼独家**耳周广域点击（Wide Area Tap）**与**左右歪头手势（Head Tilt Gesture）**、**悬停点击（Dwell Click）**，提供完全无需双手的真正无障碍电脑操控体验。

---

## 🌟 核心特性与无障碍设计

### 1. 三大免手点击体系（左侧左键，右侧右键）
* **🎧 耳机耳周广域点击（Wide Area Tap）**：
  * 利用索尼 LinkBuds 特有的声学与骨传导感应技术，轻扣或双击**左侧脸颊/耳周**即可触发【鼠标左键单击】；轻扣或双击**右侧脸颊/耳周**即可触发【鼠标右键单击】。
  * 驱动底层采用系统级热键截获，**自动屏蔽 Windows 默认的播放暂停、切歌与音量弹窗**，将其静默转化为硬件级原生鼠标按键。
* **🙆 左右歪头手势点击（Head Tilt Gesture）**：
  * **100% 免手纯头部姿态操作**，专为完全无法抬手的高位截瘫、渐冻症等肢体障碍人士研发。
  * 面向屏幕向左微偏头部（默认倾斜 $\ge 10^\circ$）触发【鼠标左键】；向右微偏头部触发【鼠标右键】。
  * **动作防晃定格锁（Tilt Freeze Lock）**：识别到歪头侧倾时，光标瞬间定格在目标落点 280ms，彻底杜绝动作晃动带跑光标的痛点！
* **⏱️ 悬停停留点击（Dwell Click）**：
  * 将光标移动到目标图标或按钮上保持静止，达到设定时间（默认 0.9 秒）后自动执行左键单击。

### 2. 彻底弃用易跑偏的点头手势与中心校准
* **告别点头跑偏**：垂直点头动作（Pitch 轴）与鼠标垂直移动轴直接重叠，极易导致光标晃动下滑。本项目全面采用独立的**横向侧倾（Roll 轴）**与**耳周敲击**，光标稳如泰山。
* **告别中心校准**：基于 Accela 相对角速度动力学驱动，随时随意转动视线，无漂移感，无需频繁按键重新校准中心。

### 3. 0 网络端口 / 纯内核匿名管道直通（Zero-Network Anonymous Pipe）
* 彻底抛弃 UDP 网络套接字与本地环回端口，电脑不开启任何网络监听端口（0 Socket、0 Port Listen）。
* 基于 Windows 内核匿名管道（Anonymous Pipe）实现底层驱动进程间内存直传，零防火墙拦截，零网络协议栈开销。

### 4. A2DP 静音保活机制（防 2.5 秒休眠）
* 攻克索尼耳机固件在“无音频播放 2.5 秒后自动关闭传感器”的休眠限制，后台以 0 增益无声维持微弱音频流保活，确保传感器随时在线。

### 5. 可视化滑块调节面板（Settings Dialog）
* **悬停停留时间滑块**：支持 0.3 秒 ~ 2.5 秒精细调节（推荐 0.7~1.0 秒）。
* **歪头触发角度阈值滑块**：支持 6° ~ 20° 角度灵敏度调节（可根据颈部舒适度个性化调整）。
* **内置实时红/蓝测试反馈区**：在面板中即可即时测试悬停、歪头与耳周点击手感。

### 6. Accela 动力学自适应滤波
* 抑制微弱生理震颤（如呼吸、脉搏），慢动极稳可像素级瞄准小按钮，快速转头迅速跟手。
* 自动联动 Windows 控制面板指针速度（`control main.cpl`）。

## 🚀 快速上手

### 1. 准备环境
本项目基于 Python 3.10+ 与 Windows 原生 API 运行。

```bash
# 1. 克隆代码仓库
git clone https://github.com/lmikey9550/Sony-LinkBudsOpen-Mouse.git
cd Sony-LinkBudsOpen-Mouse

# 2. 安装必要运行依赖
pip install -r requirements.txt
```

### 2. 生成桌面快捷方式 (推荐)
运行自带的快捷方式生成脚本，将在桌面自动创建赋予管理员提权（RunAsAdmin）的快捷方式：
```bash
python create_shortcut.py
```

### 3. 连接耳机与开启驱动
1. 佩戴好 **Sony LinkBuds Open** 耳机，确认电脑蓝牙已连接到耳机音频。
2. 双击桌面上的 **`Sony LinkBuds 头控鼠标`** 图标。
3. 托盘图标变绿即表示已成功直连，戴上耳机即可通过头部转动控制光标！

## ⚙️ 操作与交互说明

| 交互方式 | 触发动作 | 对应操作 |
| :--- | :--- | :--- |
| **广域点击 (左)** | 敲击左脸颊 / 左耳周 | **鼠标左键单击** |
| **广域点击 (右)** | 敲击右脸颊 / 右耳周 | **鼠标右键单击** |
| **头部左倾 (歪头)** | 头部向左倾斜约 10° | **鼠标左键单击** |
| **头部右倾 (歪头)** | 头部向右倾斜约 10° | **鼠标右键单击** |
| **悬停静止** | 光标在目标处停留约 0.9 秒 | **鼠标左键单击** |
| **快捷键 `F9`** | 键盘按下 F9 | **一键暂停 / 恢复头控跟踪** |
| **系统托盘右键** | 点击右下角耳机图标 | 打开灵敏度滑块面板、开关各手势、开机自启等 |

> [!TIP]
> **Sony Headphones Connect 手机 App 建议设置**：
> 在手机 App 中将“广域点击（Wide Area Tap）”开启。默认设置下左耳双击为播放/暂停，右耳双击为下一首，连接 Windows 后即可直接无缝对应左键与右键。

## 🛠️ 故障排查与自愈

* **初次连接后光标不动？**
  * Windows 在连接新蓝牙传感器节点时，偶尔可能将硬件节点临时挂起。右键点击右下角托盘耳机图标，选择 **「🔄 重新检测/修复耳机连接」** 即可一键自动修复。
* **摘下耳机后再戴上？**
  * 驱动内置智能看门狗与音频保活引擎，耳机重新连上电脑后几秒内会自动重连唤醒。
