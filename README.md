# Sony-LinkBudsOpen-Mouse 🎧🖱️

**专为手部活动不便及残障人士深度打造的 Sony LinkBuds Open (WF-L910) 全免手头控鼠标驱动系统（Windows 电脑版）。**

利用耳机内置的高精度姿态传感器（IMU / 陀螺仪），将您的头部转动转化为丝滑、自然的鼠标光标移动；并深度融合索尼独家**耳周广域点击（Wide Area Tap）**与**左右微倾手势（Head Tilt Gesture）**、**悬停停留点击（Dwell Click）**，提供完全无需双手的真正无障碍交互体验。

---

## 🌟 核心特性与无障碍设计

### 1. 三大免手点击体系（左键单击、右键单击、自动点击）
* **🎧 耳机耳周广域点击（Wide Area Tap）**：
  * 利用索尼 LinkBuds 特有的声学与骨传导感应技术，轻扣或双击**左侧脸颊/耳周**即可触发【鼠标左键单击】；轻扣或双击**右侧脸颊/耳周**即可触发【鼠标右键单击】。
  * 驱动底层采用系统级热键截获，**自动屏蔽默认的播放暂停、切歌与音量弹窗**，将其静默转化为硬件级原生按键。
* **🙆 左右微倾手势点击（Head Tilt Gesture）**：
  * **100% 免手纯头部姿态操作**，专为完全无法抬手的高位截瘫、渐冻症等肢体障碍人士研发。
  * 面向屏幕向左微偏头部（默认倾斜 $\ge 10^\circ$）触发【鼠标左键】；向右微偏头部触发【鼠标右键】。
  * **动作防晃定格锁（Tilt Freeze Lock）**：识别到微倾侧移时，光标瞬间定格在目标落点 280ms，彻底杜绝动作晃动带跑光标的痛点！
* **⏱️ 悬停停留点击（Dwell Click）**：
  * 将光标移动到目标图标或按钮上保持静止，达到设定时间（默认 0.9 秒，可通过滑块自定义）后自动执行左键单击，配备 Tobii 风格环形倒计时进度圈。

### 2. 彻底弃用易跑偏的点头手势与中心校准
* **告别点头跑偏**：垂直点头动作（Pitch 轴）与鼠标垂直移动轴直接重叠，极易导致光标晃动下滑。本项目全面采用独立的**横向侧倾（Roll 轴）**与**耳周敲击**，光标稳如泰山。
* **告别中心校准**：基于 Accela 相对角速度动力学驱动，随时随意转动视线，无漂移感，无需频繁按键重新校准中心。

### 3. 0 网络端口占用 / 内核匿名管道直传
* 彻底抛弃传统的本地 UDP 套接字回环架构，零防火墙弹窗干扰，极致低延迟跟手。
* 内置静音保活引擎，彻底解决索尼耳机 2.5 秒无音频传输自动休眠的固件难题。

### 💻 源码克隆与运行方式
如果您希望从源码启动或进行二次开发：
```bash
# 1. 克隆代码仓库
git clone https://github.com/lmikey9550/Sony-LinkBudsOpen-Mouse.git
cd Sony-LinkBudsOpen-Mouse

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 戴上耳机并连接电脑蓝牙，启动驱动主程序
python app.py
```
> （可选）运行 `python create_shortcut.py` 可在电脑桌面创建带管理员权限的快捷方式。
